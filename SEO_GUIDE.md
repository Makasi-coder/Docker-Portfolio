## 🔍 SEO Optimization

### Meta Tags (Update in index.html)

Already included:
```html
<meta charset="UTF-8" />
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
<title>Dacotah | IT Manager | Information Systems & Digital Transformation</title>
<meta name="description" content="Executive IT Manager portfolio...">
<meta name="keywords" content="IT Manager, ICT Manager...">
<meta name="author" content="Dacotah [SURNAME]">
```

**Customize these for your situation:**

```html
<!-- Primary keyword -->
<title>[Your Name] | [Your Title] | [Key Expertise]</title>

<!-- Description (155-160 characters) -->
<meta name="description" content="[Compelling 1-sentence description]. [What you specialize in]. Explore my experience, projects, and how I can help your organization.">

<!-- Keywords (3-5 main keywords) -->
<meta name="keywords" content="IT Manager, ICT Manager, Information Systems, Digital Transformation, Project Management">

<!-- Author -->
<meta name="author" content="[Your Full Name]">

<!-- Open Graph (for LinkedIn/social sharing) -->
<meta property="og:title" content="[Your Name] | [Your Title]">
<meta property="og:description" content="[Your professional summary]">
<meta property="og:type" content="profile">
<meta property="og:url" content="https://yourdomain.com">
<meta property="og:image" content="https://yourdomain.com/image.jpg">

<!-- Twitter Card (optional) -->
<meta name="twitter:card" content="summary">
<meta name="twitter:title" content="[Your Name] | [Your Title]">
<meta name="twitter:description" content="[Your professional summary]">
```

## 🏗️ Structured Data (Schema.org)

Add to `<head>` in `index.html`:

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org/",
  "@type": "Person",
  "name": "Dacotah [SURNAME]",
  "url": "https://yourdomain.com",
  "image": "https://yourdomain.com/profile-image.jpg",
  "jobTitle": "IT Manager",
  "affiliation": {
    "@type": "Organization",
    "name": "[Current Organization]"
  },
  "description": "Experienced IT Manager specializing in ICT operations, information systems, and digital transformation",
  "sameAs": [
    "https://linkedin.com/in/yourprofile",
    "https://twitter.com/yourhandle"
  ],
  "contactPoint": {
    "@type": "ContactPoint",
    "contactType": "Professional",
    "email": "your.email@example.com"
  }
}
</script>
```

This helps search engines understand your profile better.

## 📈 Google Search Console Setup

### Steps:

1. **Create account** at https://search.google.com/search-console

2. **Add property:**
   - Select "URL prefix"
   - Enter: `https://yourdomain.com`
   - Click "Continue"

3. **Verify ownership** (choose easiest method)

4. **Submit sitemap:**
   - Usually: `https://yourdomain.com/sitemap.xml`
   - Or: `https://yourdomain.com/sitemap-index.xml`

5. **Monitor in Console:**
   - Search analytics
   - Click-through rate
   - Average position
   - Impressions

## 📊 Analytics Setup

### Google Analytics (Free)

1. **Create account** at https://analytics.google.com

2. **Create property** for your domain

3. **Get tracking ID** (looks like: G-XXXXXXXXXX)

4. **Add to index.html:**
   ```html
   <!-- Google Analytics -->
   <script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
   <script>
     window.dataLayer = window.dataLayer || [];
     function gtag(){dataLayer.push(arguments);}
     gtag('js', new Date());
     gtag('config', 'G-XXXXXXXXXX');
   </script>
   ```

5. **Track events** (optional):
   - CV downloads
   - Contact form submissions
   - LinkedIn clicks

### What to Monitor

- **Users** - How many visit
- **Pages** - Which sections viewed most
- **Session duration** - How long they spend
- **Bounce rate** - Percentage leaving immediately
- **Traffic source** - Where visitors come from
- **Device type** - Mobile vs desktop
